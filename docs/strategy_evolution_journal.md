## 一、 体系演进轨迹与核心逻辑变革

本日志记录我们从“纯规则量化”向“前瞻事件驱动+均线技术结构+严格风控”转型升级的全过程：

### 阶段一：纯规则尾盘隔夜策略 (1440 TOS) 的破除与终结
* **原策略假设**：每日 14:40 机械筛选放量上涨个股，博弈次日早盘冲高溢价。
* **致命缺陷暴露**：
  1. **日K线回测存在前视偏差（偷看未来函数）**：日K线回测默认“先触及全天最高价止盈、后触及最低价止损”，但在真实时间序列推进（5分钟/逐笔仿真）中，大量标的开盘即跳水触发 -3% 止损，随后才在尾盘拉升，实盘真实收益远低于回测；
  2. **隔夜收益在统计学上为负**：A 股近 5 年全市场数据显示，昨收至今日开盘的平均收益系统性为负（-1.5bp 至 -12.1bp/天），纯博隔夜高开在统计上无长期正期望；
* **处置结论**：彻底封存该策略，停止任何实盘运作，保留其回测审计归档（Commit: `658e475`）。

### 阶段二：由“慢人一步（看后视镜）”向“先人一步（前瞻潜伏）”的纠偏
* **初期暴露的问题**：盘中看到股票大涨 7%~10%（如日发精机 +8.5%）后才反推利好，教条地告诉投资者“等回踩”。这本质上是把主力资金的“出货兑现点”当成了自己的“选股点”，属于典型的慢人一步；
* **确立的核心准则**：选股动作必须发生在：**“一手政经线索刚出炉 + 股价涨幅小于 2% 静默期 + 踩稳关键均线支撑 + 盘口暗中巨量承接”**；
* **生态位核心认知（领先散户半步即可盈利）**：
  * 我们无需也不可能在硬件和内幕上战胜顶级机构，但 A 股市场 60%~70% 的流动性由迟钝、追涨杀跌的散户贡献；
  * **散户信息传导四阶段瀑布流**：
    1. `T0 盘中萌芽期（我们的买点）`：一手消息刚发布，主力暗中吸筹，股价在 +0%~+1.5% 静默，散户还在恐慌指数或看涨幅榜；
    2. `T0 盘后发酵期`：晚间自媒体撰文、券商电话会摘要扩散、同花顺/东财热榜上升；
    3. `T1 早盘冲高期（我们的卖点）`：散户早盘竞价高挂追入，推动股价高开冲高；
    4. `T1 盘中回落期`：主力资金与前瞻资金将筹码派发给追高散户，形成套牢盘；
  * **盈利法则**：我们赚的不是预测未来一年的钱，而是**在 T0 萌芽期低位潜伏、在 T1 散户蜂拥进场时从容将筹码卖给他们的“认知与时差溢价”**。

## 二、 当前交易体系决策模型：双层量化基本面架构 (Two-Layer Quantamental System)

我们当前的选股与实战决策体系已清晰凝练为两大分工明确的层次：

```
================================================================================
【第一层：情报整合与前瞻推演层（负责“选方向与找预期差” · 先人一步）】
--------------------------------------------------------------------------------
输入源头：部委一手政策 (工信部/发改委等) + 央行流动性 + 行业突发要闻 + 顶尖研报认知差
核心任务：
  1. 穿透海量噪音，定位资金阻力最小的方向；
  2. 寻找处于 0% ~ +2% 静默期、尚未被大众散户关注的预期差标的；
  3. 领先散户半个身位，在“T0 萌芽期”提前锁定候选池。
================================================================================
                                      ↓ (初选 2~3 只候选标的)
================================================================================
【第二层：量化因子与微观结构硬门禁（负责“保质量与防踩坑” · 机械纪律）】
--------------------------------------------------------------------------------
四大因子滤网（触发任一负向红线，一票否决）：
  1.【反转因子门禁】：近 5 日涨幅处于全市场前 10% 或涨幅 > 15%，无论多好坚决不买（杜绝追高）；
  2.【聪明钱 Q 因子】：分时低信噪比大单成交占比显著，验证主力真金白银建仓（剔除散户自嗨）；
  3.【特质低波 IVOL】：剔除残差波动极大的垃圾妖股，保证底仓机构抗击力（防黑天鹅）；
  4.【均线结构与盈亏比】：股价必须踩稳 MA5/MA20 支撑，下行硬止损 ≤ 4.5%，上行目标 ≥ 10%。
================================================================================
                                      ↓ (最终输出)
             【唯一确定性交易指令：精确买入区间 + 硬止损线 + 目标止盈位】
```

## 四、 量化因子与主观前瞻融合体系 (Quantamental 架构)

针对选股体系中是否需要融合量化因子，确立以下“因子做门禁、主观做前瞻”的融合框架：

1. **反转因子 (Reversal Filter) -> 追高一票否决门禁**：
   * 凡近 5 日涨幅处于全市场前 10% 或涨幅超过 +15% 的个股，机器自动封杀买入指令（用数学杜绝追高犯错）。
2. **聪明钱 Q 因子 (Smart Money Filter) -> 主力资金验真门禁**：
   * 同一板块多个概念股中，计算日内低信噪比分钟的大单承接占比，只选择主力真金白银建仓的龙头（如今日均胜电子 13.6 亿放量）。
3. **特质波动率因子 (IVOL Filter) -> 剔除彩票型妖股**：
   * 排除残差波动过大、无业绩与机构底仓的边缘垃圾股，确保标的具备回撤抗击力。
4. **Alpha 6 量价相关性 -> 集合竞价诱多警报**：
   * 检测早盘高开无量或高开低走的资金背离信号，防范开盘接盘。
