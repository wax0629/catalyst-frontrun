## 一、 系统核心架构 (Architecture)

```
[顶层一手信源: 国常会 / 发改委 / 工信部 / 交通部 / 央行流动性 / 全球供应链突发事件]
   ↓
【第一层：前瞻催化雷达与产业链深度推导】
   • 政策级别辨识：国家战略扶持 / 实质准入准飞准入试点
   • 产业链受益端定位：优选高壁垒、高确定性的核心硬件供应商（非整车/集成）
   • 标的深度锁定：行业绝对龙头 + 核心巨头供应链
   • 预期差确认：日内涨幅 <= +2.5%（T0 萌芽静默期，大众与自媒体尚未察觉）
   ↓
【第二层：严谨量化门禁与盘口验真】
   • 门禁 1：5日反转因子排雷（近5日累计涨幅 < 15%，排除短期过热竭尽标的）
   • 门禁 2：主力资金 Q 因子（成交额 >= 3~10 亿元，机构隐蔽大单吸筹验真）
   • 门禁 3：均线生命线支撑（踩稳或企稳于 MA5 / MA20 关键支撑带）
   • 门禁 4：盈亏比评估（预期涨幅 / 潜在止损空间 >= 2.0，初始止损 <= 4.5%）
   ↓
【综合决策与试仓】
   • 仓位管理：首笔 15%~20% 试仓建仓，严禁满仓押注
   ↓
【全生命周期波段推进与动态出场状态机】
   • T0 阶段（第 1 天 · 潜伏期）：锁仓过夜，设立 -3.0%~-4.5% 初始硬止损
   • T1 阶段（第 2~3 天 · 脱离成本期）：浮盈 >= 3%，止损线上移至成本线（保本锁死）
   • T2~T5 阶段（第 4~5 天 · 主升加速期）：浮盈 >= 6%，启用动态吊灯止盈，早盘冲高分批收割
   • T5~T10 阶段（第 6~10 天 · 事实兑现期）：媒体通稿刷屏，散户疯狂进场，全额清仓出局
   • 时间止损铁律：建仓满 5 个交易日预期未催化且股价停滞，无条件换仓！
```

## 二、 每日双轨情报分类标准 (Two-Track Intelligence)

为了杜绝信息噪音并保持交易纪律，每日市场情报严格划分为两类处理：

1. **【新风向与新催化点】（进攻导向）**：
   * 必须是一手权威政策、中央流动性转向或重大突发事件；
   * 标的必须处于 **涨幅 < +2.5% 的 T0 萌芽静默期**，具有显著预期差；
   * 经过第二层量化门禁审核通过后，方可作为潜在新开仓标的。
2. **【逻辑佐证与演进跟踪】（防御/持有导向）**：
   * 行业动态扩散、后续部委跟进、大盘流动性印证、财报披露等；
   * 用于验证已有持仓的生命周期推进与止损止盈状态机演变；
   * **该类信息绝不对股票操作产生情绪化的买卖冲动**，严禁在消息明牌后盲目追高。

## 三、 “三价合一”计划交易体系 (Plan Your Trade)

成熟交易体系的核心原则是**“买入不急，买卖的都是预期价位”**。在按下买入键前，必须且只能算死三个预设价位：

1. **预期买入价 (Entry Anchor)**：预先测算 MA5 支撑位或分时均线下方挂限价单（守株待兔），绝不用市价单急着追涨；
2. **刚性止损价 (Stop-Loss Anchor)**：单笔亏损空间严格控制在 `<= 4.5%`，破位无条件平仓；
3. **目标兑现价 (Target Exit Anchor)**：催化发酵与前高阻力区，到点坚决分批收手落袋，**不赚最后一个铜板**；
4. **数学期望门槛**：$$\text{盈亏比} = \frac{\text{目标价} - \text{买入价}}{\text{买入价} - \text{止损价}} \ge 2.0$$，不达标坚决不开仓。

## 四、 科学资金管理与 1% 风险预算模型

### 1. 1% 账户风险预算铁律 (Account Risk Budget)
* **核心原则**：任何单笔交易即使触及硬止损，对总账户资产的净伤害绝不能超过 **1.0%**；
* **单票仓位上限**：
  * 中等资金（如 20 万元）：单票上限为 20%~25%（4万~5万元），承受 4% 止损时亏损仅 1,600 元（占总资金 0.8%）；
  * 微型实盘（如 1~2 万元）：采用**“双票制”（每只 35%~40%，留 20% 现金）**或**“单票单挑制”**，单笔亏损仅 100~200 多元，既锻炼真实心理，又杜绝分散导致的佣金印花税磨损。

### 2. 云条件单彻底替代“肉身盯盘”
* 散户大亏的根源在于肉眼盯盘带来的**“冲高时的贪婪延迟”**与**“跳水时的侥幸瘫痪”**；
* 交易员在开盘前通过券商 App（或同花顺）直接埋入两条指令：
  * **移动止盈单（回撤止盈）**：冲高达到目标位激活，从高点回撤 1.5% 自动市价卖出；
  * **保本止损单**：跌破预设成本保护线，服务器毫秒级自动市价斩仓；
  * 全天无需盯盘，彻底实现情绪脱敏与机械化执行。

## 八、 工具脚本与快速开始 (Scripts)

### 1. 环境准备

```bash
git clone git@github.com:wax0629/catalyst-frontrun.git
cd catalyst-frontrun
pip install -r requirements.txt
```

### 2. 实时大盘环境与催化标的盘口雷达

```bash
python scripts/catalyst_radar.py
```
*实时抓取沪深主板流动性状态，核算均胜电子、天融信等监控池标的最新盈亏比与支撑阻力位。*

### 3. 双层量化基本面门禁筛选评估

```bash
python scripts/quantamental_screener.py
```
*自动运行 5 日反转排雷、主力资金 Q 因子检验、均线支撑与盈亏比评估，输出 BUY / REJECT 决策。*

### 4. 持仓全生命周期与动态止盈止损跟踪

```bash
python scripts/trade_lifecycle_manager.py
```
*根据持仓天数与日内高点演化，自动上移移动止盈线（Trailing Stop）或激活 5 日时间止损。*
