## 策略演进与范式破局 (Paradigm Shift)

在过往的量化探索中，团队曾深度构建并实证了基于尾盘 14:40 规则的纯机械隔夜策略（TOS / 1440 策略）。但在引入 5 分钟与逐笔高精度行情进行无未来函数的严谨实盘复现后，揭示了传统纯规则量化的两大根本死穴：
1. **日K线回测的前视偏差（偷看未来函数）**：日K线回测默认“先触及最高价止盈、后触及最低价止损”，但在真实时间序列推进中，大量个股早盘开盘即跳水触及止损，随后尾盘才拉升，导致回测虚高而实盘持续负收益；
2. **隔夜收益的结构性负漂移**：在存量博弈和系统性恐慌环境下，纯技术面隔夜标的次日早盘极易遭遇集中抢跑踩踏。

**因此，本仓库正式完成核心主线跃迁，全面升级为【双层量化基本面·催化抢跑体系】。**

## 系统核心架构 (Architecture)

```
[顶层一手信源: 国常会 / 发改委 / 工信部 / 央行流动性 / 全球供应链突发事件]
   ↓
【第一层：前瞻催化雷达与产业链深度推导】
   • 政策级别辨识：国家战略扶持 / 实质准入准飞准入试点
   • 产业链受益端定位：优选高壁垒、高确定性的核心硬件供应商（非整车/集成）
   • 标的深度锁定：行业绝对龙头 + 核心巨头供应链
   • 预期差确认：日内涨幅 <= +2.5%（T0 萌芽静默期，大众与自媒体尚未察觉）
   ↓
【第二层：严谨量化门禁与盘口验真】
   • 门禁 1：5日反转因子排雷（近5日累计涨幅 < 15%，排除短期过热竭尽标的）
   • 门禁 2：主力资金 Q 因子（成交额 >= 3~10 亿元，机构隐蔽大单吸筹验真）
   • 门禁 3：均线生命线支撑（踩稳或企稳于 MA5 / MA20 关键支撑带）
   • 门禁 4：盈亏比评估（预期涨幅 / 潜在止损空间 >= 2.0，初始止损 <= 4.5%）
   ↓
【综合决策与试仓】
   • 仓位管理：首笔 15%~20% 试仓建仓，严禁满仓押注
   ↓
【全生命周期波段推进与动态出场状态机】
   • T0 阶段（潜伏期）：锁仓过夜，设立 -3.0%~-4.5% 初始硬止损
   • T1 阶段（脱离成本期）：浮盈 >= 3%，止损线上移至成本线（保本锁死）
   • T2~T5 阶段（主升加速期）：浮盈 >= 6%，启用动态吊灯止盈（高点回撤 2.5% 止盈）
   • T5~T10 阶段（事实兑现期）：媒体通稿刷屏，散户疯狂进场，全额清仓出局
   • 时间止损铁律：建仓满 5 个交易日预期未催化且股价停滞，无条件换仓！
```

## 四大标准生命周期操作规范

1. **阶段一：T0 潜伏锁定日（第 1 天）**
   * **特征**：重大一手政策盘中公布，大盘震荡跳水掩护，目标标的日内涨幅仅 `0% ~ +2%`；
   * **操作**：通过量化门禁后，在均线支撑位拿 15% 底仓，设定 -4.5% 硬止损，锁仓过夜。
2. **阶段二：T1 分歧转一致与保本锁定（第 2 天）**
   * **特征**：开盘消化恐慌后，主力大单逆势逼空脱离成本区，单笔浮盈达 +3%~+6%；
   * **操作**：**立即启动保本锁（Break-Even Stop）**，止损线上移至成本线，彻底杜绝亏损风险。
3. **阶段三：T2 ~ T5 主升加速与情绪高潮（第 3 ~ 5 天）**
   * **特征**：周末舆论发酵，券商晨会与自媒体跟进吹捧，散户疯狂跟风进场；
   * **操作**：启动**移动吊灯止盈（Trailing Stop）**，以最高价回撤 2.5% 为平仓线，让利润充分奔跑。
4. **阶段四：T5 ~ T10 政策事实最终落地（第 5 ~ 10 天 · 终极清仓日）**
   * **特征**：官方名单正式公示或签约完成，预期彻底转变为事实，“利好出尽”；
   * **操作**：借散户追高流动性全额清仓出局，锁定净利润，资金重新回归 100% 现金。

## 工具脚本与快速开始 (Scripts)

### 1. 环境准备

```bash
git clone git@github.com:wax0629/tos.git
cd tos
pip install -r requirements.txt
```

### 2. 实时大盘环境与催化标的盘口雷达

```bash
python scripts/catalyst_radar.py
```
*实时抓取沪深主板流动性状态，核算均胜电子、天融信等监控池标的最新盈亏比与支撑阻力位。*

### 3. 双层量化基本面门禁筛选评估

```bash
python scripts/quantamental_screener.py
```
*自动运行 5 日反转排雷、主力资金 Q 因子检验、均线支撑与盈亏比评估，输出 BUY / REJECT 决策。*

### 4. 持仓全生命周期与动态止盈止损跟踪

```bash
python scripts/trade_lifecycle_manager.py
```
*根据持仓天数与日内高点演化，自动上移移动止盈线（Trailing Stop）或激活 5 日时间止损。*
