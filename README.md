# Tail Overnight Strategy (TOS)
A股尾盘隔夜量化选股与风控策略

## 策略简介

Tail Overnight Strategy（简称 TOS，日常亦称“1440策略”）是一套专为 A 股短线与尾盘交易设计的量化选股与风控策略。
策略在交易日 **14:40** 触发，通过 4 层客观量化指标对前一日涨停且今日蓄势的标的进行筛选，在尾盘完成建仓，并在次日早盘执行确定性的出场状态机。

---

## 核心架构与量化标准

```
[候选池: 前一交易日涨停股票池 + 主流板块活跃股票]
   ↓
[第 1 层: 全市场成交量与情绪指标门禁] -> 判定两市总成交额(>=6800亿) + 市场情绪(涨停数/跌停数/炸板率)
[第 2 层: 板块属性与主流赛道加权] -> 判定国家战略与科技主线题材 (+20分权重)
[第 3 层: 个股流动性与异常分时过滤] -> 判定成交额(4.5~14亿) + 早盘开盘(>=-1.0%) + 分时最低(>=-2.5%)
[第 4 层: 日内形态与量比过滤] -> 判定+1.8%~+5.0%蓄势区间 + 量比(VR<=1.30防放量滞涨) + 剔除长上影
   ↓
[第 5 层: 综合决策模块] -> 统筹 4 层指标 -> 输出 BUY (建议买入) / PASS (空仓观望) / REJECT (指标不合格)
   ↓
[第 6 层: 次日动态出场执行模块] -> 
   1. 封死涨停板不卖，持股至下一交易日早盘冲高卖出
   2. 高流动性市场（成交额>1.2万亿），冲高止盈阈值上调至 +8.0%
   3. 竞价大幅低开止损 (<-2.0%) 与尾盘走弱止损 (-3.0%)
```

### 1. 全市场环境门禁
* **成交额正常（>= 6,800 亿元）**：市场流动性充足，短线接力环境健康，允许按规则买入；
* **成交额不足（< 6,800 亿元）**：市场处于低流动性状态，历史回测显示此时短线接力胜率显著偏低，**策略强制空仓，不买入任何标的**；
* **市场情绪门禁**：实时涨停家数 >= 40 家，实时炸板率 <= 30.0%，非 ST 跌停家数 <= 10 家。

### 2. 个股入围标准
* **成交额适度区间**：当日 14:40 成交额在 4.5 亿 至 14.0 亿元之间（优选 5.5~10.0 亿元）；
* **竞价开盘过滤**：T 日集合竞价开盘涨幅 >= -1.0%（剔除主力开盘抢跑出逃标的）；
* **分时最低过滤**：T 日盘中最低价跌幅 >= -2.5%（剔除日内严重破位松动标的）；
* **蓄势涨幅区间**：收盘涨幅处于 +1.8% 至 +5.0% 之间，冲高回落幅度 <= 2.0%；
* **量比过滤**：当日成交额 / 前一交易日成交额 <= 1.30（剔除放量滞涨，优先缩量蓄势）。

### 3. 次日出场规则 (超短隔夜核心原则：只赚早盘溢价，绝不在垃圾时间陪跑)
* **情景一（开盘大幅低开止损）**：若 T+1 日开盘跌幅 < -2.0%，09:25 直接市价卖出止损；
* **情景二（阶梯分层冲高止盈）**：
  * **起步保利档**：冲高最高涨幅 >= +2.0% 且从最高点回落超 0.8% 触发止盈，锁住小利润；
  * **常态大肉档**：冲高最高涨幅 >= +5.0% 且从最高点回落超 1.2% 触发止盈；
  * **高流动性狂奔档（两市成交 > 1.2 万亿）**：冲高最高涨幅 >= +8.0% 且从最高点回落超 1.5% 触发止盈；
* **情景三（10:00 时间熔断离场令）**：截至 10:00 早盘黄金半小时结束，股价冲高未能突破 +2.0% 且未封板（横盘滞涨），**10:00 准时市价全额平价清仓！绝不持有到下午，把资金腾出来防守，规避日内跳水风险**；
* **情景四（强势封死涨停板锁仓）**：盘中封死涨停板不卖，持仓至下一交易日早盘冲高卖出，获取连板溢价。

## 快速上手与运行

### 1. 环境依赖
```bash
pip install -r requirements.txt
```

### 2. 每日 14:40 运行扫描与生成指令卡
```bash
python scripts/tail_overnight_pipeline.py
```

### 3. 查看实操指令卡输出
运行后将在终端生成规范的实盘操作指令卡，包含：
1. 今日大盘成交额与流动性状态（是否允许开仓）；
2. 推荐标的、买入股数（精确到手）与预估投入金额；
3. 次日早盘各情景的挂单执行方案。
